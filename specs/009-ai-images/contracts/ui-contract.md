# UI Contract: AI Images and Availability

## Image editor (`ItemEditor` → image view)

Order below the picture and source fields:

1. **Prompt** (textarea, `ImageNode.prompt` once kept; a draft otherwise) with buttons
   **Write prompt** (`fa-wand-magic-sparkles`; gated `image-prompt`) and **Generate**
   (`fa-palette`; gated `image-generate`; disabled while the prompt is empty).
   - Write prompt with non-empty text: confirm "Replace the prompt text with a draft?";
     the text is passed as the user's idea either way.
   - After a draft: hint "Based on: Cinderhollow, Lamp Night, …".
   - Running: spinner + **Stop**; the editor stays usable.
2. **Candidate** (when present): current picture (or "No picture yet") and the candidate
   side by side (stacked below 560 px), buttons **Keep** / **Discard** / **Generate again**.
3. **Caption** field (existing) with **Write caption** (`fa-closed-captioning`; gated
   `image-caption`; hidden when the item has no picture). A proposal shows under the
   field: proposed text (editable), **Keep** / **Discard**.
4. Failures: inline `wiw-hint` error line under the action that failed, with the reason
   (FR-007, FR-016).
5. Gear button **Image settings** opens the image settings panel.

## Image settings panel (`MenuPanel`)

Sections (FormSection): **Captions** — profile (select, chat-completion profiles only),
model (FormField text, placeholder "Profile's model"), instruction (textarea);
**Prompt drafting** — profile (select with "Same as the assistant"), model, instruction,
lore size (NumberField, tokens). Footer hint: "Pictures are generated by the Image
Generation extension with its own settings."

## Folder: Caption all images without captions

- Folder editor: section "Images" with the button and the count ("3 images without
  captions"); the tree's folder context menu: item "Caption images without captions…".
- Count 0 → disabled with "No images without captions".
- Confirmation popup: "Send N pictures to <profile> (<model>) for captions?".
- Review panel (`MenuPanel` "Captions for <folder>"): progress "4 / 10", **Stop**; rows
  with thumbnail, name, editable caption or failure reason, Keep checkbox (checked when
  ready); footer **Keep selected** / **Close** (closing with unkept proposals asks).

## Availability marking (all gated controls)

- Shared helper in `ui/formControls.tsx`: `useFeature(service, feature)` and
  `<GatedButton state onClick>`; `explainUnavailable(state)` for custom triggers.
- Look: normal control at reduced emphasis plus a small `fa-triangle-exclamation` badge;
  never `opacity` alone (the old markdown look is replaced).
- Activation (click, tap, Enter/Space) opens a text popup: reason, fix, and "Reload the
  page after enabling an extension." when `reload`.
- Gated controls: assistant Send (the panel's existing banners stay); the header lore
  picking button (badge + reason in its title; the panel still opens so a profile can be
  chosen, and shows the reason on top); the markdown header button and the tree's "Export
  folder to markdown…"; Write prompt, Generate, Write caption, the folder caption action.
  Memory Books "Create memory" and the DES/DeepLore options are unchanged: they only
  appear while the extension is present.
