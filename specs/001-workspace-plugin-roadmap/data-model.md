# Data Model — Integrated Lore Workspace (001-workspace-plugin-roadmap)

Entity definitions for the plugin's own persisted state and its mapping onto the native
World Info format (field inventory in research.md R1–R3). Naming uses the plugin's
`WorldInfoWorkspace` settings namespace.

## Entities

### Workspace

The plugin's root container, persisted under
`extensionSettings['WorldInfoWorkspace']`.

| Field | Type | Notes |
|-------|------|-------|
| `version` | int | Data schema version for migrations |
| `tree` | TreeNode | Root folder node; the whole structure hangs here |
| `assistantSessions` | AssistantMessage[] | Capped history, most recent first |
| `settings` | WorkspaceSettings | User preferences (see below) |
| `bookBindings` | Record&lt;string, string&gt; | native book name → workspace root node id |

**WorkspaceSettings**: `defaultWiRootBehavior: 'sync-on-save' | 'manual'`,
`assistantProfileId?: string` (optional dedicated connection profile),
`confirmDestructive: boolean = true`, `mdMappingProfile: string` (converter presets).

### TreeNode

Union discriminated by `kind`; every node has a stable `id` (uuidv4) and `parentId`.

```
TreeNode = FolderNode | CardNode | NoteNode
```

| Field (common) | Type | Notes |
|----------------|------|-------|
| `id` | string (uuid) | Stable across moves/renames |
| `parentId` | string \| null | null only for the root |
| `kind` | 'folder' \| 'card' \| 'note' | Discriminator |
| `name` | string | Required non-empty after trim; duplicates allowed within a folder but surfaced by validation |
| `createdAt` / `updatedAt` | ISO timestamp | Audit |

### FolderNode (kind = 'folder')

| Field | Type | Notes |
|-------|------|-------|
| `isWiRoot` | boolean | Designation from FR-009; multiple roots allowed |
| `expanded` | boolean | UI state, persisted |

Children are ordered; order is user-manipulable (FR-004 move semantics).

### CardNode (kind = 'card') — Lore Entry

World Info-bound entity. Carries the **full native entry field set** verbatim
(research.md R1) plus workspace bookkeeping:

| Field | Type | Notes |
|-------|------|-------|
| `native` | NativeWiEntry | Verbatim native fields incl. `uid`; `extensions` passthrough preserved |
| `bookName` | string \| null | Native book this card belongs to when under a WI root |
| `exportState` | ExportState | Divergence tracking for FR-012 |
| `sourceRefs` | SourceRef[] | Provenance (imported from native book X; generated by assistant session Y; imported from md path Z) |

**ExportState** (drives FR-012 workspace-authoritative sync):

| Field | Type | Notes |
|-------|------|-------|
| `status` | 'new' \| 'in-sync' \| 'dirty' \| 'orphaned' | new = never exported; in-sync; dirty = workspace changed since last export; orphaned = removed from a WI root but still present in the native book |
| `lastExportedHash` | string \| null | Hash of the entry as last written to the native book |
| `lastExportedAt` | ISO timestamp \| null | |

**Validation rules**:
- `native.uid` unique within a book; reassigned from the book's free-uid pool on export if
  colliding.
- `probability` 0–100; `order` numeric; `position` 0–7; `role` 0–2; `selectiveLogic` 0–3;
  `depth` ≥ 0; timed effects ≥ 0 or null; `triggers` ⊆ GENERATION_TYPE_TRIGGERS.
- `outletName` required non-empty when `position = outlet` (per app docs).
- Native `extensions` object is preserved as-is (round-trip fidelity, R2).

### NoteNode (kind = 'note')

| Field | Type | Notes |
|-------|------|-------|
| `content` | string | Free-form, any format (md, plain text); never exported to native WI |

### AssistantMessage

| Field | Type | Notes |
|-------|------|-------|
| `id` | string (uuid) | |
| `role` | 'user' \| 'assistant' | |
| `text` | string | Display text |
| `proposals` | AssistantProposal[] | Attached change set (empty for plain replies) |
| `status` | 'pending' \| 'applied' \| 'rejected' \| 'failed' | Lifecycle of the proposal batch |
| `createdAt` | ISO timestamp | |

### AssistantProposal

One atomic, confirmable operation (FR-016): a proposal batch is applied only after user
confirmation; destructive ops always re-confirm.

| Field | Type | Notes |
|-------|------|-------|
| `op` | 'create-card' \| 'edit-card' \| 'delete-node' \| 'move-node' \| 'create-folder' \| 'delete-folder' \| 'rename-node' | |
| `targetId` | string \| null | Existing node id (null for creates) |
| `payload` | object | Op-specific; for cards = partial NativeWiEntry + target folder |
| `destructive` | boolean | delete/overwrite ops |
| `summary` | string | Human-readable description for the confirmation UI |

### MdConversionMapping

Documented rules (research.md R7), versioned so old exports re-import cleanly.

| Field | Type | Notes |
|-------|------|-------|
| `version` | int | Mapping schema version |
| `frontmatterToField` | Record&lt;string, string&gt; | YAML key → native field |
| `noteMarker` | string | Frontmatter key/value marking a file as a note (`type: note`) |
| `unmappedPolicy` | 'extensions' | Unmappable keys → card `extensions` (never dropped) |

### ExportSnapshot

Result of flattening one WI root (FR-010); transient (not persisted), logged for
debugging.

| Field | Type | Notes |
|-------|------|-------|
| `rootId` | string | FolderNode with `isWiRoot = true` |
| `bookName` | string | Native book file name (sanitized, collision-resolved like the app) |
| `entries` | Record&lt;string, NativeWiEntry&gt; | `{ "<uid>": entry }` — the exact save payload shape |

## Relationships

```
Workspace 1—1 TreeNode(root)
FolderNode 1—* TreeNode (children; arbitrary depth)
CardNode *—1 native book (bookName)      — cards under a WI root map into one book each
CardNode 1—1 ExportState                 — drives workspace→native sync (FR-012)
FolderNode 1—0..1 ExportSnapshot         — only when isWiRoot
AssistantMessage 1—* AssistantProposal   — proposal batch per assistant reply
```

## State transitions

**ExportState.status**: `new → in-sync` (successful export) ·
`in-sync → dirty` (card edited in workspace) · `dirty → in-sync` (exported again) ·
`* → orphaned` (card removed from beneath its WI root while its native counterpart
exists) · `orphaned → deleted` (user confirms removal from native book) or
`orphaned → in-sync` (card moved back under the root and re-exported).

**AssistantProposal.status**: `pending → applied | rejected` · `applied → failed` only via
partial-failure rollback (all-or-nothing batch; failed batches leave state unchanged).

**AssistantMessage.status**: `pending → applied | rejected` (batch confirmation).

## Sync semantics (FR-012, user-confirmed option A)

- Workspace is authoritative: edits mark cards `dirty`; export (on save per settings, or
  manual) writes the flattened `{ entries }` payload via `saveWorldInfo`.
- Native→workspace import is explicit; before overwriting, `WORLDINFO_UPDATED`-driven
  divergence check compares each card's `lastExportedHash` against the live native entry
  and warns when workspace `dirty` cards would be clobbered (never silently).
- Book-level `extensions` (root designation, workspace ids) survive app round-trips.

## Native format invariants (from research.md R2/R3)

- Save payload MUST contain `entries`; server rejects otherwise.
- Book file name is sanitized (`sanitize-filename`); collisions resolved `"Name (N)"`.
- Never mutate an object after handing it to `saveWorldInfo` — pass a structured clone.
